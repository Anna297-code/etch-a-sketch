# etch-a-sketch
This project is called etch-a-skecth. I am going to build a browser version of something between a skecthpad and Etch-A-Sketch.
I am going to do this by:

1.Creating a webpage with a 16x16 grid of square divs
2.Setting up a "hover" effect so that the grid divs change colour when your mouse passes over them, leaving a pixelated trail through the grid like a pen would.
3.Adding a button on the top of the screen that send the user a popup asking for the number of squares per side for the new grid. Oce entered, the existing grid should be removed, and a new grid should be generated in the same total space as before so that a new sketchpad is available.
